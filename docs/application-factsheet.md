# Kamusi Yetu - Application Factsheet

## Problem
Kenyan languages are underrepresented in digital tools, risking cultural and linguistic loss. Kamusi Yetu addresses this by building a community-driven dictionary and translation platform.

## Current Scale
- **Active Languages:** 37
- **Verified Entries:** 3,015
- **Verified Phrases:** 394
- **Bridge Coverage:** 100%

## Product Today
- Searchable dictionary with verified entries.
- Bridge-assisted translation candidates.
- Moderation workflows for quality control.

## Next Milestone
- Expand phrase packs with usage examples.
- Improve phrase-aware translation ranking.
- Launch bulk example enrichment tools.

## Use of Funds
- **Phrase and Example Enrichment:** Develop tools for contributors and moderators.
- **Moderation Operations:** Scale quality control workflows.
- **Community Outreach:** Engage contributors from underrepresented languages.
- **Infrastructure:** Enhance server capacity and tooling.
